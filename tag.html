Atividade sobre 10 tags

Tag de Cabeçalho:

A tag de cabeçalho é representada pelo elemento: "h1 a h6".
Ela é fundamental para estruturar o conteúdo, fazendo títulos e subtítulos, assim, melhorando a hierarquia visual (Tamanho).

Tag de Parágrafo:

A tag de parágrafo é representada pelo elemento: "p".
Ela é fundamental para estruturar o conteúdo, agrupando blocos de texto e criando automaticamente uma margem antes e depois da escrita, assim, facilitando a leitura e a organização do conteúdo.

>Teste de Parágrafo

Tag de Quebra de Linha:

A tag de quebra de linha é representada pelo elemento: "br".
Ela é usada para fazer a quebra de uma linha, (escrever embaixo) sem precisar iniciar um novo parágrafo. Essa tag não possui tag de fechamento igual a tag de parágrafo ou cabeçalho.

Tag de Linha horizontal:

A tag de linha horizontal é representada pelo elemento: "hr".
Ela é usada para crirar uma quebra temática ou uma separação visual entre dois conteúdos, representando uma mudança de tópico, assim como a tag de quebra de linha, ela não tem uma tag de fechamento.

Teste de Linha Horizontal

Tag de Texto em Negrito:

A tag de texto em negrito é representada pelo elemento: "b".
Ela é utilizada para destacar algum texto/palavra, colocando-o em negrito, focada no estilo.

Teste de Palavra em Negrito

Tag de Imagem:

A tag de imagem é representada pelo elemento "img".
Ela é utilizada para exibir uma imagem ao texto e não necessita de fechamento. A partir dessa tag, se utiliza o atributo "src=""" onde deve ser digitado aonde a imagem se encontra. Também é muito utilizado em conjunto o atributo "alt=""" para definir o texto alternativo da imagem (descrição).
